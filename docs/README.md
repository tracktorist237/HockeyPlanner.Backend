# Hockey Planner Backend Documentation

This directory contains the approved rules and execution plan for backend
development. The Backend Constitution is the primary rule by default. An
accepted ADR may authorize only a specific, explicitly described and limited
exception; it cannot silently override the Constitution as a whole. The
exception must state its scope, reason and consequences.
